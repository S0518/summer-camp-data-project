# 任务三：监督学习分析——disease 十分类与 disease_group 四分类对比实验

## 3.1 任务目标

任务三主要负责**监督学习疾病预测实验与特征重要性分析**。

本次更新后，任务三不再只做一个监督学习实验，而是拆分为两个层次：

```text
实验 A：原始 disease 十分类预测
目标：预测 10 种具体疾病类型，检验健康指标对具体疾病名称的区分能力。

实验 B：disease_group 四分类预测
目标：将 10 种疾病合并为 4 个疾病大类后再预测，检验健康指标对更粗粒度疾病风险方向的区分能力。
```

任务三的核心问题是：

```text
1. 当前健康指标能否预测具体疾病类型？
2. 如果将疾病合并为 4 个大类，模型效果是否会提升？
3. 哪些健康指标对疾病类型或疾病大类区分贡献更大？
4. 监督学习结果如何反过来解释无监督分群和患者风险画像？
```

需要注意：监督学习模型结果只用于数据分析、特征解释和教学展示，不作为临床诊断依据。

---

## 3.2 统一建模特征

两个监督学习实验使用相同的输入特征，区别只在于预测目标不同。

| 项目 | 内容 |
| --- | --- |
| 输入特征 X | `age`、`gender`、`bmi`、`bp_risk_score`、`cholesterol_mg_dl`、`blood_sugar_mg_dl`、`smoking_score` |
| 实验 A 预测目标 y | `disease`，原始 10 类疾病标签 |
| 实验 B 预测目标 y | `disease_group`，合并后的 4 类疾病大类标签 |
| 不使用字段 | `patient_id`、`visit_date`、`height_cm`、`weight_kg`、`bp_systolic`、`bp_diastolic` |
| 统一模型 | Logistic Regression、Decision Tree、Random Forest |
| 训练测试划分 | 训练集 80%，测试集 20% |
| 类别比例处理 | 使用 `stratify=y` 保持训练集和测试集类别比例一致 |
| 评价重点 | Accuracy、Macro Precision、Macro Recall、Macro F1-score、混淆矩阵、特征重要性 |

说明：

```text
height_cm 和 weight_kg 不直接进入模型，而是转化为 bmi。
bp_systolic 和 bp_diastolic 不直接进入模型，而是合并为 bp_risk_score。
disease 在实验 A 中作为预测目标，不作为输入特征。
disease_group 在实验 B 中作为预测目标，不作为输入特征。
```

## 3.4 实验 B：disease_group 四分类预测

### 3.4.1 实验目的

实验 B 在原始 10 分类基础上增加疾病大类合并实验。

该实验不是替代十分类任务，而是用于观察：

```text
当疾病标签从 10 类具体疾病合并为 4 类疾病大类后，
模型是否更容易捕捉健康指标与疾病风险方向之间的关系？
```

如果四分类模型明显优于十分类模型，说明当前健康指标可能更适合识别疾病大类风险方向，而不是精确预测具体疾病名称。

---

## 3.4.2 disease_group 合并规则

| disease_group 疾病大类 | 原始 disease 类型 | 合并依据 |
| --- | --- | --- |
| 代谢/血压/肾脏相关疾病 | Diabetes、Hypertension、Chronic Kidney Disease | 与血糖、血压、代谢状态和肾脏慢病管理关系较密切 |
| 心脑血管疾病 | Coronary Heart Disease、Cardiovascular Disease、Stroke | 与心血管、脑血管事件及循环系统风险相关 |
| 呼吸/肺部疾病 | Chronic Respiratory Disease、Lung Cancer | 与呼吸系统、肺部病变或吸烟暴露风险相关 |
| 肿瘤及其他疾病 | Cancer、Breast Cancer | 与肿瘤类疾病相关，当前健康指标可能只能提供有限区分信息 |

说明：

```text
Lung Cancer 同时具有肿瘤属性和肺部属性。
考虑到本项目特征中包含 smoking_score，且吸烟暴露与肺部疾病解释关系更强，
因此本实验将 Lung Cancer 归入“呼吸/肺部疾病”。
该合并规则服务于数据分析和教学展示，不代表严格临床疾病分型。
```

## 3.7 监督学习评估指标

| 指标 | 含义 | 为什么使用 |
| --- | --- | --- |
| Accuracy | 整体预测正确比例 | 直观展示模型总体效果 |
| Macro Precision | 各类别 Precision 的平均值 | 适合多分类任务，避免只关注样本多的类别 |
| Macro Recall | 各类别 Recall 的平均值 | 观察每种疾病或疾病大类是否都能被识别 |
| Macro F1-score | Precision 和 Recall 的综合指标 | 比 Accuracy 更适合多类别比较 |
| Confusion Matrix | 真实类别和预测类别的对应关系 | 查看哪些疾病或疾病大类容易被混淆 |
| Classification Report | 每个类别的 Precision、Recall、F1-score 汇总 | 细致观察各类别模型表现 |
| Feature Importance | 特征对模型预测的贡献程度 | 分析不同健康指标对疾病标签区分的影响 |
| Permutation Importance | 打乱某个特征后模型性能下降程度 | 更稳健地验证特征贡献 |

## 3.10 结果解释原则

监督学习结果解释时要避免只看准确率，需要结合十分类和四分类两个实验共同说明。

```text
如果十分类效果较弱、四分类效果明显提升：
说明当前健康指标对具体疾病名称的区分能力有限，
但对疾病所属的大类风险方向可能具有一定解释价值。

如果十分类和四分类效果都较弱：
说明当前特征对疾病标签整体区分能力有限，
监督学习结果应定位为辅助分析和特征解释，
项目重点仍然是慢性病患者内部风险画像和无监督分群。

如果 Random Forest 效果优于 Logistic Regression：
说明特征与疾病标签之间可能存在非线性关系。

如果 Logistic Regression 和 Random Forest 效果都不高：
说明仅依靠当前通用健康指标可能难以完成高精度疾病预测。
```

最终报告中建议这样表述：

```text
本项目监督学习部分通过 disease 十分类和 disease_group 四分类两个实验，
比较不同标签粒度下健康指标对疾病标签的区分能力。
实验结果不用于临床诊断，而是用于辅助理解健康指标、疾病类型和患者风险分群之间的关系。
```
